# 填写个人偏好 - 前端交互逻辑规格说明 (PRD)

## 0. 设计理念
“个人偏好设置”界面通过极具质感的设计与高密度顺滑交互（沉浸式卡片、底部联动抽屉、状态无缝刷新），将传统的静态填表转化为实时响应的“配置面板”。
**核心导向**：复杂操作一律抽屉化、层级视图互斥式平滑过渡、每步操作均配有微观动效与局部更新，绝不大面积刷新页面。

---

## 1. 核心导航与结构交互

### 1.1 模块微观 Tab 切换机制
* **触发机制**：点击四个主 Tab（院校 / 专业 / 地区 / 更多）进行主视图的切换。
* **交互动效**：
  * **字重与色值跃迁**：未激活项字体为常规灰色，激活项立刻加粗并转为深色。
  * **滑块追随标定**：选中的标签底部延展抽出一条品牌色的指示短线（由 `w-0` 过渡至 `w-6`），提供有物理惯性感的焦点强化反馈。
* **DOM 处理**：切换通过显隐核心容器（操控 `.hidden` class）完成瞬时响应，无需重载骨架和网络请求。

---

## 2. 院校偏好 (College Tab) 的交互定义

### 2.1 基础列表清单层
* **空状态 (Empty State)**：首屏无数据时，占位巨幅灰色块，提供主入口“去添加院校”。
* **删除反悔机制**：已选院校按优先级卡片堆叠，每张卡片右侧设有次级反馈灰度的“×”注销按钮。点击时瞬时注销该院校元数据并从视图抽离，同时引发上方“已选(N)”的数量统计退格重算。若触发阈值降至 0，则自动退回至空状态视图。

### 2.2 院校选择抽屉 (Bottom Action Sheet)
* **抽屉唤起与消亡**：点击添加后唤起全局黑灰色遮罩（`opacity:0 -> 100`），底部白底抽屉由视窗外 `translate-y-full` 平滑上拉进场。点击外部遮罩或内部 × 号原路退场。
* **【视图A】列表勾选视图**：
  * **智能搜索过滤**：顶部悬浮搜索条。任意字符键入后触发 `oninput`，**无需点击搜索即可实时触发节流过滤**并刷新下方列表；若有输入值，搜索尾部平滑涌现出清除键 (x)。
  * **Checkbox反馈**：院校列清单采用大尺度点击热区设计，点击后列表项左侧空心框注水般填色（品牌色）并打上白钩，右侧文案及列表背板背景发生轻微沉浸染色，传达确切的“已选中”体感。
* **【视图B】全维度筛选配置层**：
  * **翻板切换流**：在【视图A】点击“筛选”将隐藏列表DOM块，并拉出平级的表单选项区块DOM。抽屉 Header 标题同步无缝切换为“筛选条件”。
  * **胶囊多选**：点击多选项，胶囊块从灰白常态瞬间变为带粗描边的亮面高亮态。
  * **重置与应用**：底部配备等高的“重置/确定”双打按组。点击“确定”时捕捉所有激活的胶囊条件执行对象组拼，折返切回【视图A】，然后按该复合条件即时筛选数据，抽屉顶部挂出“已应用N种筛选参数”的胶囊标签。
  * **胶囊标签卸载**：用户可在【视图A】顶部快捷戳点这些小标签进行个例销毁（带过渡渐隐动画），撤离条件后列表又一次敏捷自排刷新。
* **最终回填并切断**：在抽屉确认按钮落键后，深拷贝当前勾选状态写入页面表单缓存中，抽屉执行退场动画。

## 3. 专业偏好 (Major Tab) 的交互定义

*主界面的空状态、清空联动、反悔删除交互与院校同理。关键在抽屉内。*

### 3.1 搜索平铺与级联分块的“形态自动降维”
* **搜索探针响应**：
  * **输入框为空**：下方承载标准的 **[门类第一列]-|-[专业类第二列]-|-[专业第三列]** 强联动分类选择面板。
  * **一旦输入内容**：极速隐藏上述分类级联的三列面板布局。启动平展的正则匹配搜索（例如直接匹配“汉语言”关键字），呈现单列普通列表，高亮文本片段，点击同样支持复选。清除输入框又自动恢复至分类三列联排结构。

### 3.2 三列联动级联交互
* **跨列焦点传递**：
  * 点击“门类列（首列）”某项，自身侧壁注出品牌主色粗边线表示驻留，同时将“专业类列（中列）”装载的数据清空重排并聚焦其第一个子项，随后连动装载出该子项具体的末端专业到“专业列（末列）”。交互如丝般顺滑连贯。
* **“全选”神级穿透反馈机制**：
  * **专业类（第二列全选）**：该列顶部常驻了特殊的“全选本门类”选项条位。用户单击，程序会深度遍历该门类下属的所有底层专业 ID，并往暂存勾选池悉数推入。此点击的校验态将实时响应改变，如果已被勾满，则呈注色打钩状；若再点一次，则精准反选注销这批底层级专业。
  * **专业级别（第三列全选）**：同理，设有一键“全选本类专业”按钮，极大节省一个个独立勾选的时间损耗。在全选状态下手动反去勾选某个专业的“单体”，全选母按钮的校验钩会被实时收回。

## 4. 地区偏好 (Region Tab) 的交互定义

### 4.1 "红白脸" 两极策略池
* 设定为强制二选一意向分流。地区只能存活在“优先侧”或者“不考虑池”且**绝对互斥**。
* **状态互斥转移 Toast 播报验证**：如果在搜索中点击添加“北京”进入“优先考虑群”，但代码校验到此前用户把“北京”仍在了“不考虑池”，此时触发状态覆盖。
* 面板底部会轻微浮出黑化磨砂处理的 Toast 通知：“`已将 北京 从『不考虑』移至『优先考虑』`”，持续2.5秒后消散，既确保了规则不乱也明确告知变更逻辑。

### 4.2 快捷地区包推入装载
* 提供类似“江浙沪”、“京津冀”的特殊快捷配置包（预置批量省份 ID 数组）。
* 触发时直接强行迭代注入多项数据进“优先池”列表栈内并且伴随 UI 数目增量。一旦触发互斥冲突也会合并弹窗文案（例：“`已将 3 个地区从『不考虑』移至『优先考虑』`”）。

### 4.3 拽动排序的立体反馈 (Sortable Interaction)
* 触发左上侧的入口 `意向排序` 按键。原本如贴纸般散布的优先地区标签流（Wrap流），会转化为占据满宽纵向堆叠的条目。
* **长按解绑与吸附拖曳**：在任一条目上长按，产生实体阴影使其立体起吊（Z-index提升），跟着手指进行流畅拖曳跟随。拖移时其余块面会为其闪避挪移腾出落位空隙，手指松开后块面啪嗒坠入新凹槽内完成数组数据的 `re-order`(重排序列)。意向越靠上对之后志愿生成的优先级越高。

## 5. 特殊偏好层（更多）与操作收口底座

### 5.1 胶囊拨盘式的微设置
* 像“中外合作是否考虑”等极简单的是非选项排布在页中。
* **无干扰触控**：不沿袭粗糙的 checkbox。此处右挂自定义的圆弧状拨停轨道（Segmented Button）。点击选项，按钮背光块快速在其内左移或右移覆盖落子，由于在同级域内截断了事件冒泡（`stopPropagation`），故即使连按数下也能做到即按即走、极不扰民、丝毫不跳页。

### 5.2 终极封口 - 底栏提交闸阀
* **自动补齐 Switch 拨杆**：底座包含一个拟物化拨杆，控制一个 `boolean`；点按之后纯靠 `translate` 的位移动效、辅以背景主控色从沉灰蜕变为深亮橙的过度（duration-200）表现开关状态，操作清爽。
* **确认大按栓**：这是页面最重要的出口。
  * 点击“确认”，主大按钮先进行物理级别地微内陷(`active:scale-[0.98]`)。
  * 紧跟其后进入提交状态锁，按钮文本即刻置换并旋出转轮图标 `<i class="fa fa-spinner"></i> 提交中...`。
  * 模拟数据写入完成（例如0.8秒后），文本跳字置换为带“✓ 操作成功”，最后历经 2 秒缓释复原。这形成了一套绝佳的心里安全闭环防伪校验反馈体系。
